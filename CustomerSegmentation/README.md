# Customer Segmentation — RFM + K-means

**Автор:** Черниченко Надія, ТТП-42  
**Датасет:** [Online Retail, UCI Machine Learning Repository](https://archive.ics.uci.edu/dataset/352/online+retail).

**Звіт:** [Сегментація клієнтів за RFM та K-means](results/REPORT_UA.md).

Мета — поділити клієнтів на групи за давністю останньої покупки, кількістю замовлень і сумою витрат.
Використання Online Retail замість запропонованих у завданні датасетів потребує погодження викладача.

Джерело даних: Chen, D. (2015), DOI [10.24432/C5BW33](https://doi.org/10.24432/C5BW33), ліцензія [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Файл `data/Online Retail.xlsx` включено без змін; очищені таблиці та RFM-показники отримано кодом проєкту.

## Запуск у Windows

Відкрийте папку `CustomerSegmentation` у терміналі та виконайте:

```powershell
py -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe src/segmentation.py
```

Вхідний файл `data/Online Retail.xlsx` уже є в проєкті. Результати записуються в `results/`.

## Етапи роботи

1. **Попередня обробка:** видалення пропусків, скасувань і непозитивних кількостей/цін; розрахунок RFM. Логарифмування зменшує вплив екстремальних значень, `StandardScaler` вирівнює масштаби ознак.
2. **EDA:** гістограми RFM і діаграми зв’язків між ознаками.
3. **K-means:** порівняння k=2..8 за Elbow і Silhouette; автоматичний вибір найбільшого Silhouette Score.
4. **Оцінювання та інтерпретація:** Silhouette Score, медіанні RFM-показники, кількість клієнтів і частка виручки кожного кластера.
5. **Візуалізація:** PCA, розміри кластерів, частки виручки та теплова карта профілів.

## Результати

## Особливості розрахунку

Дані належать до 2010–2011 років. Повернення та скасування виключені, а не відняті від продажів; наведені суми не є чистою виручкою після повернень. Назви сегментів описують їхні RFM-профілі. PCA використовується для відображення, кластеризація виконується за трьома перетвореними RFM-ознаками.
